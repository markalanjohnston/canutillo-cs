🪑 Have a Seat

Set up the room, paste a class list, drag students into seats, print. Everything stays in this browser only — nothing is uploaded.

Students

Click a card to cycle its tag. Drag it onto a seat. Drag a seated student back here to unseat them. ⚙ edits name and custom label.

Room

While this panel is open, click a seat to cycle standard → special → not available. The room (seats, aisles, notes) is shared by every period tab.

Aisle between columns
Aisle between rows

Or click the striped gap between two seats to toggle an aisle there.

    "Left" and "Right" are from a student's seat, facing the front.

    standard special not available Talker Accommodation custom label

    Import students

    Paste one name per line, or paste CSV / spreadsheet cells. With a header row the Name column (or First + Last) is used; without one, the first column is used, and two-column lines are read as Last, First. There is no file upload — paste only.

    Edit student

    Clicking the card cycles: none → Talker → Accommodation → your label → none.
