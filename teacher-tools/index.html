About these tools

Built by a CS teacher for real classroom use. Everything on this page is plain HTML and JavaScript served as static files: there is no backend, no database, and no analytics. Tools that work with student names (rosters, seating charts) keep that information in your browser's local storage on your own machine — it is never transmitted anywhere. Clearing your browser data clears it.

Don't take my word for it. These claims are auditable: view the page source in your browser (right-click → View Page Source, or DevTools → Network tab — you'll see no requests carrying your data), or read every line of code in the public repository at github.com/markalanjohnston/canutillo-cs. What's served is exactly what's in the repo.
